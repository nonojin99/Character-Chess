# 캐릭터 체스 — Character Chess

해리포터 마법사 체스를 모티브로 한 캐릭터 체스.

규칙은 정식 체스와 완전히 같고, **말의 이동·공격 연출 · 잔해 · 덱** 만 캐릭터로 살아 움직인다.

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **말별 고유 공격** | 찌르기 / 베기 / 내려찍기 / 주력탄 / 폭발 / 왕의 일격 / 결계 붕괴 |
| **잔해 (Debris)** | 잡힌 말이 스프라이트 파편으로 부서져 판 위에 남음 (물리 + 베이크) |
| **실루엣 그림자** | 말 실제 실루엣에서 내려오는 소프트 그림자 (광원 방향 반영) |
| **덱 선택** | 백/흑이 서로 다른 테마를 고를 수 있음 |
| **AI 3단계** | 초보(깊이1) · 중수(깊이3) · 고수(깊이5) |
| **온라인** | Supabase Realtime 브로드캐스트 (선택) |
| **3D 보드** | Three.js 프로토타입 (클릭 수 두기, 테마 재질, 파편 물리) |

## 덱 (테마)

| id | 이름 | 감성 |
|----|------|------|
| `oath` | 강철 서약 | 석상 · 황동/흑철 |
| `abyss` | 심연 결계 | 자수정 결정 |
| `ruby` | 홍옥 결사 | 붉은 옥 + 흑금 |
| `porcelain` | 청화 서원 | 조선 백자 + 청화 |

## 실행

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

또는 `index.html` 을 브라우저로 직접 열어도 됩니다 (art base64가 인라인 로드).

## 조작

1. 시작 화면에서 **모드** (2인 / AI / 온라인), **AI 난이도**, **백·흑 덱** 선택
2. 클릭으로 말 선택 → 합법 수 표시 → 다시 클릭으로 이동
3. 캡처 시 말이 부서지며 잔해가 판에 남음
4. **3D 보드** 버튼으로 Three.js 뷰 전환 (클릭 수 두기 가능)

## 빌드

소스를 수정한 뒤에는 반드시:

```bash
node build.js
```

`shell.html` + `logic/*` + `render/*` 를 인라인한 `index.html` 이 생성됩니다.

## 프로젝트 구조

```
logic/     체스 엔진, AI, PGN, 매치
render/    보드, 이펙트, 물리, 3D, 테마
net/       Supabase 트랜스포트
tools/     시트 스튜디오, QC
sim/       테스트·메트릭
art-*.js   테마별 스프라이트 (멤이스)
```
